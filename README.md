一句话简介

▎ UlearnBetter：别让收藏夹替你学习。把收藏的学习视频丢给桌宠小原，它会把视频自动整理成一片可以"走进去学"的知识星图，每天告诉你该学什么、为什么。

（短版，约 20 字：把吃灰的收藏视频，变成每天会提醒你的知识星图。）

---

项目详细说明

一、项目背景

我们每天都会刷到有用的学习视频，点个收藏，说一句"以后再学"，然后它就和几十条别的收藏混在一起吃灰。收藏
不等于学会。问题不在人，而在"看到"和"学会"之间少了一步：内容太杂、理不清，没人提醒，也看不见自己的进步。

UlearnBetter 是一个学习陪伴式智能体，专门补上这一步。目标用户是靠 B 站、YouTube 自学，同时推进好几条学习线（课业、量化、AI 前沿等）的大学生和自学者。

三、功能亮点

1. 一个入口，丢进来就行：把视频链接贴进或拖进桌宠小原的输入框，后端自动跑完 抓字幕 → 模型生成笔记 →
   编译 → 归类 四步。每一步的进度都实时显示，失败时写明原因，也可以重试。
2. 智能体整理，结果可解释、可撤销：自动识别资料讲了什么、拆出哪些概念、归到哪个学习目标，并给出置信度和理由。高置信的结果自动接受，低置信的放进"待确认"。每次整理都能一键撤销，用户改过的结果下次重新整理也不会被覆盖。
3. 星图潜航，知识是活的：一个主题是一片星空，一个概念是一颗星。点开一颗星，周围的卡片按知识形状生成：定义、对比、流程、结构、可勾选的实操清单、可以拖动参数的公式卡（曲线实时重算）。每条出处都能回到原视频的具体秒数。
4. 每天告诉你学什么、为什么：今天页最多给 5 件事，顺序是到期复习、各目标路线上的下一颗星、没做完的实操。每条都附理由，理由完全由学习记录拼成。排期规则是公开的确定规则，不靠模型生成。
5. 看得见进步：离开一颗星时点一下"记得 / 忘了"，就决定了它的亮度和下次复习时间（间隔 1 / 3 / 7 / 14 / 30 天）。全景图把所有目标放在一张图里，学会的星会变亮，整组没学的地方标成缺口，并标出下一步。
6. Obsidian 风格的笔记阅读器：星图背后的 Markdown 笔记随时可以读。支持双链（可以跳到具体某一节）、反向链接、大纲、callout、公式、mermaid 全景图和视频时间戳。
7. 桌宠小原，常驻的学习伙伴：页面上没有常驻聊天框，点小原才会弹出对话面板，它可以拖到屏幕任意位置。它能看到你此刻在看哪颗星、哪张卡、滑块停在哪个数值，提问时会结合这些回答。但确认整理结果必须由你本人来点。
8. 省钱、可信、数据归你：模型只用来生成笔记、识别和归类，掌握度、复习排期、今日计划都是本地规则算的，日常使用不消耗 token。笔记和字幕一律当作数据处理，不会被当成指令执行。所有数据都是本地文件，没有云端锁定。

四、运行方式

环境要求：Node.js 20 以上。如果要用"贴链接生成星图"，还需要 Python 3 和能正常运行的 yt-dlp。

# 1. 安装依赖（首次运行，或拉取更新之后）
cd server && npm ci && cd ../concept-graph && npm ci && cd ..

# 2. 一条命令启动预置演示（后端、前端、数据一起启动）
cd server && npm run demo
# 浏览器打开 http://localhost:5173/#/today

- 不配置任何 API Key，也能完整体验今天、全景、星图潜航、资料、笔记五个视图。预置数据是 3 个学习目标、31 颗知识星，由真实流水线和真实模型从 6 个公开视频生成；另附 17 天学习记录，这部分是脚本模拟的，经真实接口写入。
- 启用 AI 功能（助手问答、自动整理、贴链接生成星图）：打开 http://127.0.0.1:4000/settings，选一家模型并填入密钥，保存后立即生效，不用重启。
- 贴链接生成星图的额外环境：
  - pip install -U yt-dlp，并确保它在 PATH 里；
  - 后端默认调用 python3（Windows 上是 python），可以用 PYTHON_BIN 指定；
  - 访问视频站需要代理时，设置 RECORD_VIDEO_PROXY；
  - 应用内只处理有字幕的视频。
- 运行测试：
python -m unittest discover -s tests                     # Python
node --experimental-strip-types --test tests/*.test.mjs  # 前端逻辑
cd server && npm test                                    # 后端
cd concept-graph && npm run build && npm run lint        # 前端构建与 lint
